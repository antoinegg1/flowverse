# Parallel Flame Chase Git/PR Token Efficient Main Monitor

Parallel Flame Chase with isolated Git/PR lanes, Report Share, token-efficient instructions, and
natural main-update steering.

## Usage

Select `parallel_flame_chase_git_pr_token_efficient_main_monitor` as the flow and provide the
ordinary seven Git/PR agent roles: one planning orchestrateor and two alternating actors for each
of three lanes. Receipt integration and main-update delivery are runtime-owned; no reviewer agent
is used.
