# Git/PR Token-Efficient Main-Monitor Lane

Work only in the assigned clone. Commit and push substantive task changes, record the official
evaluator once per relevant tree, then open and ready a receipt-backed PR. Trust runtime-validated
receipts and Main Update Monitor facts. Avoid repeated status, log, hash, full-diff, receipt, and
unchanged-tree evaluator checks. On a monitor event, briefly choose rebase, continue, or combine
and preserve the choice in the LaneReport. Never perform remote release or deployment actions.
