# Parallel Ralph Git/PR Lane

Each round is a fresh session of the same lane model. Continue from the assigned clone and prior
same-lane report rather than conversational memory. Commit and push a substantive experiment,
record the official evaluator with `pfc evaluate`, and propose improvements through a receipt-backed
PR. Treat other lane reports as shared evidence. Never perform remote release or deployment actions.
