# Parallel Flame Chase Git/PR Main Monitor

Parallel Flame Chase with isolated Git/PR lanes, Report Share, and natural main-update steering
into active lane sessions.

## Usage

Select `parallel_flame_chase_git_pr_main_monitor` as the flow and provide the ordinary seven
Git/PR agent roles: one planning orchestrateor and two alternating actors for each of three lanes.
Main updates are detected and delivered by the runtime; no reviewer agent is used.
