# Flame Chase Report Share

`flame_chase_report_share` keeps ordinary Flame Chase's two fresh alternating agents and shared
working tree. It additionally asks each completed turn for a bounded structured report and gives
that exact report to the next partner as claims that must be checked.

It adds no parallel lanes, Git/PR integration, reviewer, or global knowledge store. Set `budget` to
zero to let an external active-time limit stop the run.
